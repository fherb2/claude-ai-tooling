# translation-task — Übersetzung software-entwicklungsnaher Dokumente

Kein allgemeiner Übersetzer: ausgelegt auf Texte, in denen Fachbegriffe, Codeblöcke, Dateinamen und Produktnamen zwischen Prosa stehen und je eigenen Regeln folgen. Nicht auf eine Sprachrichtung festgelegt.

**Status:** Anweisungen vollständig, Frontmatter gesetzt. Kein stiller Trigger nötig — die Auslösung geht vom Nutzer aus („übersetze mir das") und wird von der regulären Description erreicht. In der Gesamt-README beschrieben.

**Offen:**

- Die fünf Punkte unter „Noch nicht festgelegt" in der `SKILL.md` einzeln besprechen und dort festschreiben: Namenskonvention für Zieldateien, Sync-Workflow zwischen zwei Sprachfassungen, Umgang mit Lizenz- und Rechtstexten, Ein-Absatz-pro-Zeile-Formatierung, Ton und Anrede.

Die Erprobung am Zielort findet statt, wenn der Skill dort gebraucht wird.

**Bewusst offen gelassen:** Das Glossar (`glossar.md`) wird nicht mitgeliefert. Es entsteht im Betrieb und ist projektabhängig; eine leere Vorlage würde nur suggerieren, es gäbe einen Startbestand.
