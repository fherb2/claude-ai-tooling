- Bevor Du ein neues Artefakt / File erstellst oder Änderungen an Bestehenden vornimmst, erkläre erst, was Du tun wirst und ich entscheide, ob Du das Artefakt nun erstellen / ändern kannst.

- Erstelle Code in Artefakten nur, wenn es sich um neuen Code handelt oder bestehenden Code, der so weitgehend geändert wird, dass er den alten Code in sehr großen Stücken vollständig ersetzt. In Artefakten immer, wenn es sich um eine ganze Datei handelt. Artefakte dürfen auch bei neuem Code in Form von ganzen Funktionen oder Klassen handelt. Ansonsten im Chat in dem weiter unten beschriebenen Schema.
- Einmal erstellte Code-Artefakte sollten normalerweise nicht mehr geändert werden, es sei denn, ich bitte Dich darum. Grund: Im Web-Frontend entstehen manchmal Fehler, die das Artefakt unbrauchbar machen. In der Regel kopiere ich den Inhalt nach der Erzeugung auf meinen Rechner: Bei Änderungen, sage mir also, wo ich etwas einfügen oder ersetzen soll. Das kannst Du im Chat-Verlauf oder bei längeren Einfügungen auch als separates Artefakt machen. Achte vor allem darauf, dass solche Codeänderungen im Einfügeort von mir nicht missverstanden werden können und natürlich: Immer auf die exakte Einrückung achten.
- Benutze für bei Code-Änderungen und -Hinzufügungen, die Du im Chat ausführst, ein einheitliches Schema aus einen "Vorher"-Codeblock und einen nachfolgenden "Ersetzen-mit-Codeblock". Im ersten Codeblock zeigst Du die zu ändernden Zeilen vor der Änderung, wie ich sie mit der Suchen-Funktion des Editors finden kann. Im nachfolgenden Codeblock ist dann der Code enthalten, den ich an die Stelle der Zeilen aus dem ersten Codeblock exakt dahin setzen soll. Beachte unbedingt die originalen Einrückungen. Verwende zur Beschreibung der Änderungs-/Einfügestelle niemals Zeilennummern. Nur den Code so, wie ich ihn für den ersten Codeblock beschrieben habe. Und schreibe "Vorher" / "Nachher" vor den Codeblock und nicht hinein. 
- Bevor Du ein Artefakt erzeugst oder eine Code-Änderung, dann prüfe immer zuerst, ob Du dazu noch Fragen hast. In diesem Falle fange das Artefakt noch nicht an zu schreiben, sondern Frage mich und lasse alle Fragen geklärt sein, bevor Du tatsächlich anfängst..
